Đoạn code nên thuộc: search có debounce

type SearchState<T> =
  | { status: 'idle' | 'loading'; data: T[] }
  | { status: 'success'; data: T[] }
  | { status: 'error'; data: T[]; error: unknown };

// `search` must be stable (wrap it in useCallback) or the effect re-runs every render
function useDebouncedSearch<T>(
  query: string,
  search: (q: string, signal: AbortSignal) => Promise<T[]>,
  delay = 300,
): SearchState<T> {
  const [state, setState] = useState<SearchState<T>>({ status: 'idle', data: [] });

  useEffect(() => {
    const q = query.trim();
    if (!q) {
      setState({ status: 'idle', data: [] });
      return;
    }
    const controller = new AbortController();
    const timer = setTimeout(async () => {
      setState(s => ({ status: 'loading', data: s.data }));
      try {
        const data = await search(q, controller.signal);
        if (!controller.signal.aborted) setState({ status: 'success', data });
      } catch (error) {
        if (!controller.signal.aborted) setState(s => ({ status: 'error', data: s.data, error }));
      }
    }, delay);
    // New keystroke or unmount: drop the pending call and ignore its response
    return () => {
      clearTimeout(timer);
      controller.abort();
    };
  }, [query, search, delay]);

  return state;
}

Đoạn code nên thuộc: infinite scroll + pull-to-refresh

type Page<T> = { items: T[]; next?: string };
type Mode = 'initial' | 'more' | 'refresh';

function useInfiniteList<T extends { id: string }>(fetchPage: (cursor?: string) => Promise<Page<T>>) {
  const [items, setItems] = useState<T[]>([]);
  const [cursor, setCursor] = useState<string>();
  const [hasMore, setHasMore] = useState(true);
  const [loading, setLoading] = useState<Mode | null>('initial');
  const [error, setError] = useState<unknown>();
  const inFlight = useRef(false); // onEndReached can fire several times in a row

  const load = useCallback(async (mode: Mode) => {
    if (inFlight.current || (mode === 'more' && !hasMore)) return;
    inFlight.current = true;
    setLoading(mode);
    setError(undefined);
    try {
      const page = await fetchPage(mode === 'more' ? cursor : undefined);
      setItems(prev => {
        const base = mode === 'more' ? prev : [];
        const seen = new Set(base.map(i => i.id));
        return [...base, ...page.items.filter(i => !seen.has(i.id))];
      });
      setCursor(page.next);
      setHasMore(Boolean(page.next));
    } catch (e) {
      setError(e); // keep the items already on screen
    } finally {
      inFlight.current = false;
      setLoading(null);
    }
  }, [cursor, hasMore, fetchPage]);

  useEffect(() => { load('initial'); }, []); // eslint-disable-line react-hooks/exhaustive-deps

  return { items, loading, error, loadMore: () => load('more'), refresh: () => load('refresh') };
}

// Usage
<FlatList
  data={items}
  keyExtractor={item => item.id}
  renderItem={renderItem}            // stable via useCallback, row wrapped in React.memo
  onEndReached={loadMore}
  onEndReachedThreshold={0.5}
  refreshing={loading === 'refresh'}
  onRefresh={refresh}
  ListFooterComponent={loading === 'more' ? <ActivityIndicator /> : null}
  ListEmptyComponent={loading === 'initial' ? <ActivityIndicator /> : error ? <RetryButton onPress={refresh} /> : <Text>Chưa có dữ liệu</Text>}
/>

Bài code review mẫu: tìm lỗi trong 10 phútSample code review: find the bugs in 10 minutes

function Users({ navigate }) {
  const [users, setUsers] = useState([]);
  const [page, setPage] = useState(1);

  useEffect(() => {
    fetch(`/users?page=${page}`)
      .then(r => r.json())
      .then(d => setUsers([...users, ...d]));
  }, [page]);

  useEffect(() => {
    AppState.addEventListener('change', s => s === 'active' && setPage(1));
  }, []);

  return (
    <FlatList
      data={users}
      renderItem={({ item, index }) => (
        <Row key={index} user={item} onPress={() => navigate(item)} />
      )}
      onEndReached={() => setPage(page + 1)}
    />
  );
}
Xem đáp án (8 lỗi)Show the answer (8 bugs)
  • Stale closure: users trong effect là giá trị cũ. Dùng setUsers(prev => [...prev, ...d]).
  • Không xử lý lỗi: thiếu .catch và không kiểm tra r.ok.
  • Race condition: không hủy request; trang về sai thứ tự sẽ chèn sai. Dùng AbortController trong cleanup.
  • onEndReached gọi nhiều lần: không có cờ đang tải và không biết đã hết trang, nên tải trùng trang.
  • Rò rỉ listener: subscription AppState không được remove() trong cleanup.
  • setPage(1) không reset danh sách: dữ liệu trang 1 bị nối thêm vào cuối. Nếu page đang là 1 thì effect còn không chạy lại.
  • Key sai chỗ: key trong renderItem bị bỏ qua và lại là index. Dùng keyExtractor={u => u.id}.
  • Re-render thừa: renderItem và onPress tạo mới mỗi lần render nên Row có memo cũng vô ích; useState([]) không có type sẽ thành never[] trong TS.
  • Stale closure: users inside the effect is an old value. Use setUsers(prev => [...prev, ...d]).
  • No error handling: there's no .catch, and r.ok is never checked.
  • Race condition: requests are never cancelled, so pages that come back out of order land in the wrong place. Abort them in the cleanup.
  • onEndReached fires repeatedly: there's no in-flight flag and no notion of the last page, so the same page gets loaded twice.
  • Leaked listener: the AppState subscription is never remove()d in a cleanup.
  • setPage(1) doesn't reset the list: page 1 gets appended to the end again. And if page is already 1, the effect doesn't even re-run.
  • Key in the wrong place: React ignores a key returned from renderItem, and it's the index anyway. Use keyExtractor={u => u.id}.
  • Wasted re-renders: renderItem and onPress are recreated on every render, so memoizing Row achieves nothing. Also, useState([]) without a type is inferred as never[] in TypeScript.

Đoạn code nên thuộc: search có debounce

class SearchPage extends StatefulWidget {
  const SearchPage({super.key, required this.search});
  final Future<List<Repo>> Function(String query) search;

  @override
  State<SearchPage> createState() => _SearchPageState();
}

class _SearchPageState extends State<SearchPage> {
  Timer? _debounce;
  int _requestId = 0;
  bool _loading = false;
  Object? _error;
  List<Repo> _results = const [];

  void _onChanged(String text) {
    _debounce?.cancel();
    _debounce = Timer(const Duration(milliseconds: 300), () => _run(text.trim()));
  }

  Future<void> _run(String query) async {
    final id = ++_requestId; // only the latest request may update the UI
    if (query.isEmpty) {
      setState(() {
        _results = const [];
        _error = null;
        _loading = false;
      });
      return;
    }
    setState(() {
      _loading = true;
      _error = null;
    });
    try {
      final results = await widget.search(query);
      if (!mounted || id != _requestId) return;
      setState(() {
        _results = results;
        _loading = false;
      });
    } catch (e) {
      if (!mounted || id != _requestId) return;
      setState(() {
        _error = e;
        _loading = false;
      });
    }
  }

  @override
  void dispose() {
    _debounce?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        TextField(
          onChanged: _onChanged,
          decoration: const InputDecoration(hintText: 'Search repositories'),
        ),
        if (_loading) const LinearProgressIndicator(),
        if (_error != null)
          Text('Something went wrong', style: TextStyle(color: Theme.of(context).colorScheme.error)),
        Expanded(
          child: ListView.builder(
            itemCount: _results.length,
            itemBuilder: (context, i) => ListTile(
              key: ValueKey(_results[i].id),
              title: Text(_results[i].name),
            ),
          ),
        ),
      ],
    );
  }
}

Đoạn code nên thuộc: infinite scroll + pull-to-refresh

class PageResult<T> {
  const PageResult(this.items, this.next);
  final List<T> items;
  final String? next; // null means there are no more pages
}

class _FeedPageState extends State<FeedPage> {
  final _scroll = ScrollController();
  final _items = <Post>[];
  final _ids = <String>{};
  String? _cursor;
  bool _hasMore = true;
  bool _loading = false; // guards against duplicate page requests
  Object? _error;

  @override
  void initState() {
    super.initState();
    _scroll.addListener(() {
      if (_scroll.position.extentAfter < 500) _loadMore();
    });
    // setState is not allowed inside initState, so start after the first frame
    WidgetsBinding.instance.addPostFrameCallback((_) => _loadMore());
  }

  Future<void> _loadMore() async {
    if (_loading || !_hasMore) return;
    setState(() {
      _loading = true;
      _error = null;
    });
    try {
      final page = await widget.fetchPage(_cursor);
      if (!mounted) return;
      setState(() {
        for (final p in page.items) {
          if (_ids.add(p.id)) _items.add(p); // dedupe by id
        }
        _cursor = page.next;
        _hasMore = page.next != null;
      });
    } catch (e) {
      if (mounted) setState(() => _error = e); // keep what is already on screen
    } finally {
      if (mounted) setState(() => _loading = false);
    }
  }

  Future<void> _refresh() async {
    if (_loading) return; // don't race a page that is still loading
    _loading = true;
    try {
      final page = await widget.fetchPage(null);
      if (!mounted) return;
      setState(() {
        _items
          ..clear()
          ..addAll(page.items);
        _ids
          ..clear()
          ..addAll(page.items.map((p) => p.id));
        _cursor = page.next;
        _hasMore = page.next != null;
        _error = null;
      });
    } catch (e) {
      if (mounted) setState(() => _error = e); // the old list stays visible
    } finally {
      _loading = false;
    }
  }

  @override
  void dispose() {
    _scroll.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    if (_items.isEmpty && _loading) return const Center(child: CircularProgressIndicator());
    if (_items.isEmpty && _error != null) {
      return Center(child: TextButton(onPressed: _loadMore, child: const Text('Retry')));
    }
    return RefreshIndicator(
      onRefresh: _refresh,
      child: ListView.builder(
        controller: _scroll,
        physics: const AlwaysScrollableScrollPhysics(),
        itemCount: _items.length + (_hasMore || _error != null ? 1 : 0),
        itemBuilder: (context, i) {
          if (i == _items.length) {
            return _error != null
                ? TextButton(onPressed: _loadMore, child: const Text('Retry'))
                : const Padding(
                    padding: EdgeInsets.all(16),
                    child: Center(child: CircularProgressIndicator()),
                  );
          }
          final post = _items[i];
          return PostTile(key: ValueKey(post.id), post: post);
        },
      ),
    );
  }
}

Bài code review mẫu: tìm lỗi trong 10 phútSample code review: find the bugs in 10 minutes

class UserList extends StatefulWidget {
  @override
  State<UserList> createState() => _UserListState();
}

class _UserListState extends State<UserList> {
  List users = [];
  int page = 1;
  final controller = ScrollController();

  @override
  void initState() {
    super.initState();
    load();
    controller.addListener(() {
      if (controller.position.pixels == controller.position.maxScrollExtent) {
        page++;
        load();
      }
    });
    Connectivity().onConnectivityChanged.listen((_) => load());
  }

  void load() async {
    final res = await http.get(Uri.parse('https://api.example.com/users?page=$page'));
    setState(() => users.addAll(jsonDecode(res.body)));
    ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text('Loaded page $page')));
  }

  @override
  Widget build(BuildContext context) {
    return Column(children: [
      Text('Users'),
      ListView(
        controller: controller,
        children: users.map((u) => UserTile(user: u)).toList(),
      ),
    ]);
  }
}
Xem đáp án (8 lỗi)Show the answer (8 bugs)
  • Dùng state và context sau await: không kiểm tra mounted; widget đã dispose thì setState và ScaffoldMessenger sẽ lỗi.
  • Không xử lý lỗi: không try/catch, không kiểm tra statusCode; jsonDecode payload lớn chạy trên UI isolate.
  • Tải trang trùng: listener ở đáy cuộn gọi nhiều lần liên tiếp, page++ nhảy trang; không có cờ đang tải và không biết hết trang.
  • Rò rỉ subscription: stream connectivity không được cancel trong dispose, và mỗi lần đổi mạng lại nối thêm trang hiện tại vào danh sách.
  • Không dispose ScrollController.
  • Unbounded height: ListView nằm trong Column không có Expanded sẽ báo lỗi layout.
  • ListView(children:) build toàn bộ danh sách; dùng ListView.builder và Key theo id.
  • Type và chữ ký: List users là List<dynamic> không có model; void load() async không await được và lỗi bị nuốt, nên dùng Future<void>; thiếu const và super.key.
  • State and context used after an await: mounted is never checked, so setState and ScaffoldMessenger blow up if the widget has been disposed.
  • No error handling: no try/catch and no statusCode check, and jsonDecode runs on the UI isolate even for large payloads.
  • Duplicate page loads: the bottom-of-list listener fires several times in a row, so page++ skips pages. There's no in-flight flag and no notion of the last page.
  • Leaked subscription: the connectivity stream is never cancelled in dispose, and every network change appends the current page to the list again.
  • The ScrollController is never disposed.
  • Unbounded height: a ListView inside a Column without Expanded throws a layout error.
  • ListView(children:) builds the entire list up front. Use ListView.builder with keys based on id.
  • Types and signatures: List users is a List<dynamic> with no model; void load() async can't be awaited and swallows errors, so make it Future<void>; const and super.key are missing.
