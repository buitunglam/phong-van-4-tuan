React Native trong 8 tuần

Tổng hợp từ các JD React Native trên TopDev, JobsGO, ITviec, Workable, LinkedIn và các trang tuyển dụng quốc tế. Mỗi tuần có mục tiêu, checklist, bài lab và câu hỏi tự kiểm tra. Cuối trang là bộ câu hỏi phỏng vấn theo cấp độ.

Các JD thực sự yêu cầu gì

Đếm trên 9 JD đọc chi tiết (4 Việt Nam, 5 quốc tế, Junior → Senior). Thanh xanh là yêu cầu bắt buộc, thanh tím là điểm cộng.

Phải có
  • JavaScript ES6+ và TypeScript vững
  • React hooks, vòng đời render, tối ưu re-render
  • Một thư viện state: Redux Toolkit (Saga), MobX hoặc Zustand
  • REST API, xác thực, xử lý lỗi; WebSocket cho realtime
  • Build và phát hành lên App Store, Google Play
  • Unit test và E2E test
  • Git flow / trunk-based, code review
  • Debug và tối ưu hiệu năng iOS + Android
Điểm cộng tạo khác biệt
  • Native module bằng Swift / Kotlin
  • New Architecture: JSI, TurboModules, Fabric
  • Expo, EAS Build / Submit / Update
  • CI/CD mobile (GitHub Actions, Fastlane, EAS Workflows)
  • Firebase, push notification, deep linking, analytics
  • Sentry / Datadog, theo dõi crash
  • Mentor, dẫn dắt kiến trúc

LinkedIn bổ sung gì

Từ khoảng 10 tin tuyển dụng và bài đăng của recruiter trên LinkedIn (Việt Nam, Mỹ, Ấn Độ, Pakistan). Phần lớn trùng với danh sách trên. Các điểm dưới đây xuất hiện rõ hơn ở LinkedIn:

  • Kinh nghiệm production thật: app đã release và được bảo trì lâu dài, có portfolio link store. Một recruiter ghi rõ Expo, Jest, RNTL, Detox/Maestro chỉ là nice-to-have, “không phải tiêu chí lọc”.
  • Vận hành sau release: triage crash production từ Sentry, staged rollout với EAS.
  • Nâng cấp phiên bản React Native và Expo SDK được ghi thành yêu cầu riêng.
  • Build tool native: Xcode, Gradle, Fastlane; profiling bằng Xcode Instruments và Android Studio Profiler.
  • Cách recruiter lọc Senior: tìm “React Native” đi kèm JSI / Fabric / TurboModules cùng Swift hoặc Kotlin và C++.
  • Stack hay gặp: Redux + Redux-Saga (Uniswap), REST/GraphQL + Firebase (SnapTec), TDD và CI/CD với GitLab runner (Builder.ai).
